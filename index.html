Overview

A production-ready, highly modular cross-platform UI architecture framework developed for Unity. Originally conceived as a Bachelor’s Thesis (TFG), it has evolved into a professional open-source tool for the game development community. Its core mission is to eliminate repetitive UI setup by delivering a fully decoupled, scalable, and adaptable interface architecture.

Problem Solved

Instead of wasting valuable time reinventing the wheel and building UI architecture from scratch for every project, Modular UI allows developers to deploy clean, decoupled, and scalable UI systems in seconds, seamlessly integrated into any Unity codebase.

Key Features & Technical Architecture

  • Clean Architectural Foundation 🧱: Built from the ground up following SOLID principles. It heavily relies on the Observer pattern for decoupled, event-driven communication and utilizes Factory patterns to handle dynamic, independent component creation cleanly.
  • Instant Production-Ready Templates 📦: Deploy fully functional Main Menus, HUDs, Pause Menus, Dialogue Systems, and Inventories straight out of the box.
  • Cross-Platform Adaptation 📱💻🕶️: Responsive layouts, scaling, and input schemes that automatically and dynamically adapt across Desktop, Mobile, and Virtual Reality (VR).
  • Real-Time Visual Customization 🎨: Switch your game’s entire aesthetic instantly using a powerful ScriptableObject-driven styling system; zero code modifications required.
  • Advanced Integrated Systems ⛓️: Includes pre-integrated, robust sub-systems like drag-and-drop inventories and node-based dialogue trees.

Target Audience

Whether you are a solo indie developer looking to speed up prototyping, a UI/UX designer wanting to test layouts instantly, or a programming team in need of a clean, architecture-driven UI foundation, this tool is built to fit your workflow.

Technologies Used

Unity, C#, SOLID Architecture, Observer & Factory Patterns, ScriptableObjects, Cross-Platform (Desktop, Mobile, VR)

La Sobremesa

Company

Lotify

Description

Developed for Lotify, this is a hybrid physical + digital party game that blends a physical board game (tablero) with a mobile companion app. Built using Godot 4.3, the digital companion manages the game flow, offering interactive menus, dice rolling, roulette mechanics, scoreboards, and 9 diverse mini-game modes. The game supports 2 to 4 teams and features dynamic board mechanics including advances, retrocessions, and final showdown sequences.

Key Features & Mechanics

  • Teams: Tailored for 2 to 4 teams playing simultaneously with custom names.
  • Dynamic Difficulty: Scales dynamically based on each team's score and performance streak.
  • 4 Mini-game Categories:
    • Show: Humming (Tararear), Mimicry (Mímica), and Drawing (Dibujar/Gestures).
    • Wit (Ingenio): Logic, 3-Word challenges, Yes/No questions, Banned Words, and Forbidden Letters.
    • Know-It-All (Sabelotodo): Trivia quizzes, Primary School questions, Roulette challenges, and Pasapalabra.
    • Mentalist: Telepathy challenges, including matching or mismatching answers.
  • Decision Squares: Special tiles allow teams to decide their own challenge or choose a challenge for their rivals.
  • Final Sequence: Reaching the final square triggers a climax where teams must overcome 3 consecutive mini-game challenges in a row to win.
  • All or Nothing (Todo o Nada): A final showdown mechanism that resolves ties or deadlocks when teams get stuck.

My Role

  • Programmed the core game loop, turn management, and state machine in GDScript.
  • Implemented the dynamic difficulty scaling and team performance streak tracking algorithms.
  • Coded the final sequence logic, enabling dynamic challenge cycling across categories.
  • Developed UI menus, mini-games, and custom audio integration for timers, dice rolls, and victory events.

Technologies Used

Godot 4.3, GDScript, JSON Data Parsers, Mobile UX Design
